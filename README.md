# バスケ道場（v0.2）

ミニバス〜中学生向けの、バスケのルール・用語・戦術を学ぶクイズと、家でサイレントボールを使うドリル練習のWebアプリ（PWA）です。
iPad / iPhone の Safari で開き、「ホーム画面に追加」するとアプリのように使えます。インストール権限は不要です。

公開URL：https://akira0216.github.io/basket-dojo/

## できること

| 機能 | 内容 |
|---|---|
| 選手（プロフィール） | 1台に何人でも作れる。名前とアイコンを選ぶ |
| クイズ道場 | 3リーグ × 8ステージ × 10問 ＝ **240問**。4択＋コート図（選手・パス・動きのアニメーション）。★1〜★3で評価 |
| リーグ | **B2**（用語・ルール・ファウル・しんぱんの合図）→ **B1**（せめの基本・1線2線3線・ヘルプ・速こう・リバウンド・1対1の技）→ **Bプレ**（スクリーン・ピック&ロール・ゾーン・プレス・セットプレー・試合さいごの判だん・NBA/Bリーグ）。前のリーグを全部★2以上で開放 |
| ふくしゅう | まちがえた問題がたまり、もう一度チャレンジできる |
| ドリル | **28種類**（ハンドリング・ドリブル・シュート・フットワーク・パス・ディフェンス・体づくり）。きほん／ステップアップ／チャレンジの3段階。「今日のおすすめ」3つ。ショットクロック風タイマー（音声つき） |
| 成長 | XP・レベル・称号、ステータス6種（レーダーチャート・総合）、使える技12種、3ポイントせいこう率 |
| 毎日 | デイリーミッション（クイズ5問＋ドリル1つで +30XP）、れんぞく日数、2週間カレンダー |
| バッジ | 15種類（全問制覇など） |
| バックアップ | 記録のコピー／ファイル保存、読みこみ |

クイズは毎日のミッション（5問）と★集めのやり直しで、約3ヶ月で全問制覇できる量にしています。

## ファイル構成

```
index.html            画面のもと
css/style.css         見た目
js/app.js             アプリ本体（画面・クイズ・タイマー・XP計算）
js/store.js           記録の保存（端末内 localStorage）
js/court.js           コート図（SVG）
data/questions.js     クイズのしくみと、問題・コート図の書き方の説明
data/quiz-b2.js       B2リーグの問題   ← 問題を増やすときはここ
data/quiz-b1.js       B1リーグの問題
data/quiz-bp.js       Bプレリーグの問題
data/drills.js        ドリル           ← ドリルを増やすときはここ
manifest.webmanifest  ホーム画面に追加したときの設定
sw.js                 オフラインで使うための設定
icons/                アイコン
```

## パソコンで動かしてみる

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。

## iPad / iPhone で使う（GitHub Pages で公開する場合）

1. GitHub に新しいリポジトリを作り、このフォルダの中身をアップロードする（`.claude` フォルダは不要）
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）を iPad / iPhone の **Safari** で開く
4. 共有ボタン → **「ホーム画面に追加」**
5. **ホーム画面のアイコンから**開いて選手を作る

> ⚠️ Safari のタブで作った記録と、ホーム画面のアプリの記録は別あつかいです。最初から必ずホーム画面のアイコンから使ってください。
> ⚠️ 記録は端末の中だけに保存されます。ときどき「せってい → 記録のバックアップ」で保存しておくと安心です。

## 問題を追加する

各リーグのファイル（例：`data/quiz-b2.js`）の、ステージの**さいご**に1行追加します。書き方のくわしい説明は `data/questions.js` にあります。

```js
//  [ルール, 問題文, [正しい答え, まちがい, まちがい, まちがい], 説明, コート図(なくてもよい)]
['c', '問題文', ['正しい答え', 'まちがい1', 'まちがい2', 'まちがい3'], '説明',
  { o: { 1: 'top', 2: 'rw' }, x: { 1: 'top', 2: 'rw' }, ball: 1, pass: [['o1', 'o2', 1]] }],
```

- 正しい答えはいつも先頭に書きます（表示のときにシャッフルされます）。
- ルールは `'c'`＝共通、`'m'`＝ミニバス、`'g'`＝中学・一般。
- 問題のIDは「ステージID-何番目」で自動で決まるので、ステージのとちゅうに入れたり、順番を入れかえたりしないでください（ふくしゅうや全問制覇の記録がずれます）。

ファイルを更新して公開しなおしたら、`sw.js` の `VERSION` も上げてください。

## 注意

- 文章は小学4年生までに習う漢字を目安にしています（それ以外はひらがな）。
- ルール問題（とくにミニバスと中学・一般のちがい）は、JBA の最新の競技規則で確認してから使ってください。
