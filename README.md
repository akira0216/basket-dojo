# バスケ道場（v0.1 / フェーズ1 MVP）

ミニバス〜中学生向けの、バスケのルール・用語・戦術を学ぶクイズと、家でサイレントボールを使うドリル練習のWebアプリ（PWA）です。
iPad / iPhone の Safari で開き、「ホーム画面に追加」するとアプリのように使えます。インストール権限は不要です。

## できること（v0.1）

| 機能 | 内容 |
|---|---|
| 選手（プロフィール） | 1台に何人でも作れる。名前とアイコンを選ぶ |
| クイズ道場 | B2リーグ 3ステージ（コートと用語 / 基本ルール / ファウル）全25問。4択＋コート図。★1〜★3で評価 |
| ふくしゅう | まちがえた問題がたまり、もう一度チャレンジできる |
| リーグ | B2 → B1 → Bプレ。前のリーグを全部★2以上で開放（B1・Bプレの問題はフェーズ2以降） |
| ドリル | 8種類。タイマー（カウントダウン・セット・休けい・音声）付き |
| 成長 | XP・レベル・称号、ステータス6種、使える技12種、3ポイントせいこう率 |
| 毎日 | デイリーミッション（クイズ5問＋ドリル1つで +30XP）、れんぞく日数、2週間カレンダー |
| バッジ | 10種類 |
| バックアップ | 記録のコピー／ファイル保存、読みこみ |

## ファイル構成

```
index.html            画面のもと
css/style.css         見た目
js/app.js             アプリ本体（画面・クイズ・タイマー・XP計算）
js/store.js           記録の保存（端末内 localStorage）
js/court.js           コート図（SVG）
data/questions.js     クイズ問題 ← 問題を増やすときはここ
data/drills.js        ドリル     ← ドリルを増やすときはここ
manifest.webmanifest  ホーム画面に追加したときの設定
sw.js                 オフラインで使うための設定
icons/                アイコン
```

## パソコンで動かしてみる

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開きます。

## iPad / iPhone で使う（GitHub Pages で公開する場合）

1. GitHub に新しいリポジトリを作り、このフォルダの中身をアップロードする（`.claude` フォルダは不要）
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）を iPad / iPhone の **Safari** で開く
4. 共有ボタン → **「ホーム画面に追加」**
5. **ホーム画面のアイコンから**開いて選手を作る

> ⚠️ Safari のタブで作った記録と、ホーム画面のアプリの記録は別あつかいです。最初から必ずホーム画面のアイコンから使ってください。
> ⚠️ 記録は端末の中だけに保存されます。ときどき「せってい → 記録のバックアップ」で保存しておくと安心です。

## 問題を追加する

`data/questions.js` の `QUESTIONS` に追加します。`answer` は `choices` の何番目が正解か（0から数える）。表示のときに選たくしはシャッフルされます。

```js
{
  id: 'b2r-10', stage: 'b2-rules', rule: 'common',   // rule: common / mini / general
  q: '問題文',
  court: { highlight: ['paint'] },                    // 任意。paint / three / ft / center
  choices: ['正しい答え', 'まちがい1', 'まちがい2', 'まちがい3'],
  answer: 0,
  explain: '解説',
},
```

ファイルを更新して公開しなおしたら、`sw.js` の `VERSION` も上げてください。

## 注意

- 文章は小学4年生までに習う漢字を目安にしています（それ以外はひらがな）。
- ルール問題（とくにミニバスと中学・一般のちがい）は、JBA の最新の競技規則で確認してから使ってください。
